# Monolith Vault 🛡️

A zero-knowledge, client-side web application that generates highly secure passwords and analyzes password entropy in real-time. Built entirely with Vanilla JavaScript.

## ✨ Features

* **Interactive Password Generator:** Customize length (8-128 characters) and toggle specific character sets (Uppercase, Lowercase, Numbers, Symbols).
* **Real-Time Analyzer:** Calculates password entropy and estimates brute-force cracking time on every keystroke.
* **Zero-Knowledge Architecture:** 100% client-side processing. No passwords are ever sent to a server.
* **Modern UI:** Single Page Application (SPA) design with an integrated Dark Mode.

## 🚀 Tech Stack

* **HTML5:** Semantic structure.
* **CSS3:** Custom variables, flexbox/grid layouts, and responsive design.
* **Vanilla JavaScript (ES6+):** Modular logic for DOM manipulation and mathematical entropy calculations.

## ⚙️ Local Setup

Since this is a client-side application, no build tools or servers are required.
1. Unzip the downloaded file.
2. Open `index.html` in any modern web browser.
